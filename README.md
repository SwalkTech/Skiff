# Skiff
<img width="1536" height="1024" alt="Skiff 是一艘只做 SSH 的小艇：一个开在原生窗口里的 SSH 客户端。 它记 (1)" src="https://github.com/user-attachments/assets/5fe58ff6-f6c2-4450-a062-d08aad7c58f9" />

Skiff 是一艘只做 SSH 的小艇：一个开在原生窗口里的 SSH 客户端。

它记住你的主机，先确认对方的主机密钥，再让你登录。连接之后是一块等宽终端，可以输入、看输出，窗口变大变小时远端也会跟着调整。断开时会话一起结束，不留在后台。

连上之后可以打开远程目录，上传和下载文件。可以同时连接多台主机，右边分栏切换。终端保留远端发来的颜色。左侧会显示这台服务器的 CPU、内存、磁盘、负载和网速。顶栏可以在明亮和暗黑之间切换。有新版本时会先询问再更新。端口转发、远程桌面和 AI 助手不在这艘小艇上。

窗口由 [Viva](https://github.com/vivaui/viva) 绘制。SSH 会话、终端网格和主机数据写在这个仓库的 Go 代码里。客户端还在起步。
